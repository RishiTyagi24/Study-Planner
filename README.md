# StudyMate — Student Study Planner

StudyMate is a simple, responsive study-task planner made with **HTML, CSS and vanilla JavaScript**. It is designed as a beginner web development project for a first-year BTech student.

## Features

- Add tasks with a subject and priority
- Mark tasks as completed
- Delete tasks
- Filter tasks: All, Pending and Completed
- Dashboard counters for total, pending and completed tasks
- Saves tasks in the browser using `localStorage`
- Responsive layout for mobile and desktop
- Displays the current date

## Technologies used

- **HTML5** — page structure and form
- **CSS3** — layout, colors, responsive design and styling
- **JavaScript** — task operations, filters, counters and local storage

No framework, backend or installation is required.

## Run the project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

## Upload to GitHub

1. Sign in to [GitHub](https://github.com/).
2. Click **New repository** and name it `student-study-planner`.
3. Choose Public (if you want to show it in your portfolio).
4. Create the repository.
5. Click **Add file → Upload files**.
6. Upload `index.html`, `style.css`, `script.js` and `README.md`.
7. Click **Commit changes**.

### Publish with GitHub Pages

1. Open your repository and select **Settings**.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Wait a minute and refresh the Pages section. GitHub will show your website link.
